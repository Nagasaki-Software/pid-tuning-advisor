# PID調整アドバイザー 設計書

- 作成日：2026-11-14
- フォルダ：`pid-tuning-advisor`（リポジトリの直下）
- 版：0.1.0（初版）
- 画面デザイン：開発時に Claude Design で作成（非公開。完成した画面は `docs/manual/取扱説明書.md` の写真を参照）

## 1. このアプリで出来ること（要約）

温度調節計の記録（設定値・出力%・測定値）と、今の P・I・D の設定を入力すると、
P・I・D をどう直せばよいかを数値で示す Windows アプリ。

- 対象の設備：蒸気と水の熱交換器。蒸気バルブの開度で水温を制御する
- 対象の調節計：横河電機 UT35A / UT32A を初期設定とし、ほかの調節計にも合わせられる
- 使う人：設備の担当者 1人が、自分の PC で使う
- 将来：汎用化して GitHub で公開することを考えている（初版では公開しない）

## 2. 確定した要件

| 項目 | 決めたこと |
|---|---|
| 入力するデータの場面 | 設定値を変えたとき／設定値一定で温度が揺れるとき／手動で出力を変えたとき |
| データの形式 | CSV ファイル。どの列が何かは画面で選ぶ |
| 解析の方法 | 設備の特性を推定して計算する。波形の診断も併記する |
| アプリの形 | Windows の窓アプリ（PyQt6 ＋ pyqtgraph） |
| 見た目 | Mac風。ただし窓の最上部（タイトルバー）は Windows 標準のまま |
| 調節計ごとの違い | 「プロファイル」として変更・保存できる。初期値は UT35A / UT32A |
| 文字 | Meiryo UI（無ければ Meiryo） |
| アイコン | オリジナル。窓の左上・タスクバー・アプリ本体（ショートカット）に出す |

## 3. 使い方の流れ

1. ［CSVを開く］で記録ファイルを読み込む
2. 「データの列」で、時刻・設定値・出力・測定値の列を選ぶ
3. 「現在のPID設定」に P・I・D、「入力レンジ」に下限・上限を入力する
4. グラフ上の青い帯をドラッグして、解析する区間を選ぶ（初期状態は全体）
5. 「場面」（自動判定が初期値）と「調整の好み」（安定重視／標準／速さ重視）を選ぶ
6. ［解析する］を押す
7. 右側に修正案・診断・推定した設備のくせ、中央下に予想グラフが出る

## 4. 画面

画面デザイン（上記リンク）のとおり。1つの窓を左・中央・右に分ける。

### 4.1 上部のツールバー
- ［CSVを開く］、読み込んだファイル名と行数・記録間隔
- 調節計プロファイルの選択、［設定…］（調節計の設定画面を開く）
- ［解析する］

### 4.2 左：入力
- **データの列**：時刻・設定値・出力（%）・測定値の列を選ぶ。
  時刻の列が無い CSV のために、時刻で「（なし）」を選ぶと「記録の間隔（秒）」の入力欄が出る
- **現在のPID設定**：P・I・D。単位と名前はプロファイルに従う（UT35A なら 比例帯 %・積分時間 秒・微分時間 秒）。
  使っていない動作は「OFF」と入力する
- **入力レンジ**：下限・上限（比例帯の基準になる）
- **場面**：自動判定／設定値の変更／温度の揺れ（ハンチング）／手動で出力を変更
- **調整の好み**：安定重視／標準／速さ重視
- **補助機能を使用中**（チェック）：オーバーシュート抑制などの機能（UT35A のスーパー機能）を使っているデータのとき入れる。入れると注意書きが出る

### 4.3 中央：グラフ
- 上段：設定値（灰色の破線）と測定値（青）
- 下段：出力 %（緑）
- 解析する区間を青い帯で表示。両端をドラッグして変える。上下のグラフで連動する
- 予想グラフ：設定値を変えたときの測定値の動きを、現在の設定（橙の破線）と提案の設定（青）で重ねる。
  下に、それぞれの行き過ぎ量と落ち着くまでの時間を並べる

### 4.4 右：結果
- **PIDの修正案**：P・I・D の「現在 → 提案」、理由の文、［提案値をコピー］
- **波形の診断**：場面、行き過ぎ量、揺れの周期、落ち着くまでの時間 など（場面により項目が変わる）
- **推定した設備のくせ**：バルブ 1% あたりの温度変化、時定数、むだ時間、当てはまり具合（%）
- 注意書き

### 4.5 調節計の設定画面
プロファイルを選び、値を変えて保存する。

- ［複製して新規］：今のプロファイルを写して、別名で保存する
- ［初期値に戻す］：同梱の UT35A / UT32A の値に戻す
- 同梱のプロファイル（UT35A / UT32A）は上書きできない。変えたいときは複製する

### 4.6 アイコン
オリジナルのアイコンを使う。絵柄は、画面デザインの「アイコン案」の A（応答カーブ）に決定。
青い角丸の四角（#0A66D8）に、設定値を表す白い破線と、行き過ぎてから落ち着く白い波形を描く。

  白・線の端と角は丸・太さは通常版 18、簡略版 26

## 5. 調節計プロファイル

調節計ごとに変わる値をひとまとめにしたもの。

| 項目 | 選べる値 | UT35A / UT32A の初期値 | 取扱説明書の根拠 |
|---|---|---|---|
| P の表し方 | 比例帯（%）／比例ゲイン | 比例帯（%） | 6.4 節 |
| I の表し方 | 秒／分／回/分 | 秒 | 6.4 節 |
| D の表し方 | 秒／分 | 秒 | 6.4 節 |
| P の範囲・刻み | 数値 | 0.1〜999.9、刻み 0.1 | 6.4 節（0.0 は 0.1 として動作） |
| I の範囲・刻み・OFF | 数値、OFF の可否 | 1〜6000、刻み 1、OFF 可 | 6.4 節 |
| D の範囲・刻み・OFF | 数値、OFF の可否 | 1〜6000、刻み 1、OFF 可 | 6.4 節 |
| 設定値を変えたときの出力 | すぐに動く／急には動かない | すぐに動く（標準PID制御モード ALG=0） | 8.3 節 |
| 微分動作のかけ方 | 測定値の変化／偏差の変化 | 測定値の変化（PV微分型） | 8.3 節 |
| 動作の向き | 逆動作（加熱）／正動作（冷却） | 逆動作 | 18.2 節（DR 初期値 RVS） |
| 制御周期 | ミリ秒 | 200 | 一般仕様 |
| 出力の範囲 | 下限〜上限（%） | 0.0〜100.0 | 18.2 節（OL 0.0%、OH 100.0%） |

- 根拠にした資料：横河電機 UT35A/UT32A User's Manual IM 05P01D31-01EN 第7版
- 保存先：`%APPDATA%\pid-tuning-advisor\profiles\<名前>.json`（UTF-8）。
  同梱の UT35A / UT32A はプログラムの中に持ち、ファイルには置かない
- 最後に使ったプロファイルと入力値（P・I・D・入力レンジ）は
  `%APPDATA%\pid-tuning-advisor\settings.json` に覚えておく

### 取扱説明書から読み取れなかった点（解釈で補う）
- **「急には動かない」（定値制御モード）の中身**：説明書は「設定値変更で出力が跳ねない」とだけ書いている。
  このアプリでは「比例動作も測定値にだけかける方式（I-PD）」として計算する
- **微分動作のなまし（フィルタ）**：記載が無い。なましなしで計算する
- **スーパー機能の中身**：記載が無いので再現しない（注意書きを出す）
- **積分のたまり過ぎ防止（AR）**：説明書の方式（偏差が比例帯の一定割合を超えたら PID 計算を止める）は再現せず、
  「出力が上下限に張り付いている間は積分を止める」という簡易な方式で計算する

## 6. 解析の中身

### 6.1 CSV の読み込み
- 文字コード：UTF-8（BOM 付き含む）で読み、失敗したら cp932 で読む
- 区切り：カンマ・タブ・セミコロンを自動判定
- 見出し行：数値の行が始まる直前の行を見出しとみなす。それより上の行（記録計の説明行など）は読み飛ばす
- 時刻：日時の文字（`2026/11/14 10:00:00`、`2026-11-14 10:00:00.5`、`10:00:00` など）か、秒の数値。
  先頭を 0 秒とした経過秒に直す
- 数値に直せない行は捨て、捨てた行数を画面に出す
- 記録の間隔は、時刻の差の中央値とする。間隔がばらつく場合は、等間隔に直してから解析する（直線でつなぐ）

### 6.2 設備の特性の推定
設備を「1次遅れ＋むだ時間」で表す。

    T × (測定値の変化の速さ) + 測定値 = K × (L 秒前の出力) + b

- K：出力 1% あたりの測定値の変化（℃/%）
- T：時定数（秒）、L：むだ時間（秒）、b：出力 0% のときの測定値に当たる値

求め方：
1. 選んだ区間の出力と測定値を使う（設定値や現在の PID は使わない。3つの場面で同じ方法が使える）
2. 点数が 3000 を超えるときは、平均して 3000 点以下に間引く
3. T と L の候補を順に試す。候補ごとに、K と b と「最初の状態の影響」は一次式の最小二乗で求まる
4. 実測と計算の差の二乗和がいちばん小さい T・L を選び、その周りを細かく探し直す
5. 当てはまり具合（%）＝ 100 ×（1 − 差の大きさ ÷ 測定値の変動の大きさ）

numpy だけで計算する（scipy は使わない。配布物を小さくするため）。

### 6.3 数値の提案を出す条件
次のすべてを満たすとき、数値の提案を出す。満たさないときは、診断と調整の方向だけを出し、理由を画面に書く。

- 区間内の出力の変化幅が 2% 以上
- 区間内の測定値の変化幅が、入力レンジの 0.5% 以上
- 当てはまり具合が 70% 以上
- K の符号が動作の向きと合っている（逆動作なら K > 0）
- T・L が探した範囲の端に張り付いていない
- 区間内のデータが 30 点以上

### 6.4 提案の計算
推定した K・T・L から、IMC／SIMC 法で求める。

- 目標の速さ τc：速さ重視 = L、標準 = 2L、安定重視 = 4L
  （L が極端に小さいときは、記録の間隔と制御周期の 2 倍のうち大きいほうを L の下限として使う）
- PI（D を使わない）：ゲイン = T ÷ (K × (τc + L))、積分時間 = T と 4 × (τc + L) の小さいほう
- PID：ゲイン = (T + L/2) ÷ (K × (τc + L/2))、積分時間 = T + L/2、微分時間 = T × L ÷ (2T + L)
- PI と PID の選び方：測定値の細かいばらつき（ノイズ）から、微分動作で出力がどれだけばたつくかを見積もる。
  ばたつきが 2% 未満なら PID、2% 以上なら PI（D = OFF）を提案する
- 調節計の単位への変換：
  - 単位なしのゲイン = ゲイン[%/℃] × 入力レンジの幅[℃] ÷ 100
  - 比例帯(%) = 100 ÷ 単位なしのゲイン。比例ゲインで表す調節計では、単位なしのゲインをそのまま使う
  - 積分：秒はそのまま、分 = 秒 ÷ 60、回/分 = 60 ÷ 秒
  - 微分：秒はそのまま、分 = 秒 ÷ 60
- プロファイルの刻みに丸め、範囲に収める。範囲に収めるために値を変えたときは、その旨を画面に書く

### 6.5 予想グラフ
- プロファイルの計算式で PID を再現し、推定した設備と組み合わせて、制御周期ごとに計算する
- 計算式（UT35A の標準PID制御モード、取扱説明書 8.3 節）：
  出力 = (100 ÷ 比例帯) ×（偏差 + 偏差の積分 ÷ 積分時間 + 微分時間 × 測定値の変化の速さ）
  ※偏差・測定値は入力レンジの幅に対する % に直して計算する
- 出力は、プロファイルの出力の範囲で頭打ちにする
- 設定値の変え方：場面が「設定値の変更」なら記録と同じ変え方。それ以外は、区間の平均の測定値から入力レンジの 5% 上げる
- 現在の設定と提案の設定のそれぞれで、行き過ぎ量と落ち着くまでの時間を出す
- 提案の設定のほうが両方とも悪いときは、注意書きを出す

### 6.6 再現の確認（場面が「設定値の変更」のときだけ）
- 記録と同じ設定値の変え方で、現在の PID と推定した設備を組み合わせて計算し、記録の測定値と比べる
- 合い具合（%）を出す。50% 未満なら
  「入力した PID・入力レンジ・計算のしかたが実機と違うか、記録に外乱が含まれている可能性があります」と注意書きを出す
- 数値の提案は止めない（提案を出す条件は 6.3 のとおり）

### 6.7 波形の診断
| 場面 | 自動判定の条件 | 出す項目 |
|---|---|---|
| 設定値の変更 | 区間内で設定値が入力レンジの 0.5% 以上変わる | 変化の幅、行き過ぎ量（℃と変化幅に対する %）、揺れの周期、揺れの収まり具合、落ち着くまでの時間 |
| 手動で出力を変更 | 設定値が一定で、出力が階段状（同じ値が続いたあと急に変わる） | 出力の変化量、測定値の変化量、63% 到達までの時間 |
| 温度の揺れ | 上のどちらでもなく、測定値が設定値をまたいで 3 回以上往復する | 揺れの幅（測定値・出力）、周期、揺れの傾向（収まる／続く／広がる）、出力の上下限への張り付き |

- 落ち着くまでの時間：測定値が「変化幅の ±5%」に入り、以後出ない時刻まで
- 揺れの周期：山と山の間隔の平均
- どの場面にも当てはまらないときは、その旨を表示し、設備の特性の推定だけを試みる

### 6.8 調整の方向（数値の提案を出せないときにも出す）
取扱説明書 6.4 節の手動調整の指針に沿う。上から順に当てはめ、最初に合った 1 つを表示する。
「揺れがある」は、山が 2 つ以上あり、2 つ目の山が 1 つ目の 25% より大きいこと。

| 順 | 波形の様子 | 表示する方向 |
|---|---|---|
| 1 | 揺れがあり、D を使っていて、周期が微分時間の 4 倍より短い | 微分時間を短くする |
| 2 | 揺れがあり、I を使っていて、周期が積分時間より長い | 積分時間を長くする |
| 3 | 揺れがある（上の 2 つ以外） | 比例帯を広げる |
| 4 | 揺れはないが、行き過ぎが変化幅の 10% より大きい | 積分時間を長くする |
| 5 | 設定値からずれたまま戻らない（区間の終わりで偏差が入力レンジの 0.5% 以上残る） | 積分時間を短くする（I が OFF なら入れる） |
| 6 | 行き過ぎが 10% 以下で、数値の提案より落ち着くまでが 2 倍以上長い | 比例帯を狭める、または積分時間を短くする |
| 7 | どれにも当てはまらない | 「大きな問題は見当たりません」と表示する |

比例ゲインで表す調節計では、「比例帯を広げる」を「比例ゲインを下げる」、「狭める」を「上げる」と言い換える。
順 6 は数値の提案があるときだけ判定する。

## 7. 画面に出す注意書き
- 提案は目安。設定を変えたあとの記録でもう一度解析して確かめる
- 水の流量やバルブ開度が大きく違う運転では設備のくせが変わるので、その条件の記録で解析し直す
- 「補助機能を使用中」にチェックがあるとき：推定がずれる可能性がある

## 8. エラーの扱い
| 状況 | 動き |
|---|---|
| CSV が読めない、数値の列が無い | 原因を書いたメッセージを出す |
| 選んだ列に数値でない行がある | その行を捨て、捨てた行数を出す |
| 時刻が前後している、重複している | 並べ直し、重複を除き、注意を出す |
| 区間内のデータが 30 点未満 | 解析せず、メッセージを出す |
| P・I・D・入力レンジが未入力、範囲外 | その欄を赤くし、解析しない |
| 提案を出す条件を満たさない | 診断と調整の方向だけを出し、満たさなかった条件を書く |
| 想定していないエラー | 内容をダイアログに出し、`%APPDATA%\pid-tuning-advisor\error.log` に記録する（握りつぶさない） |

## 9. 作り

### 9.1 使うもの
- Python、PyQt6、pyqtgraph、numpy
- 開発時のみ：pytest、pytest-qt
- pyqtgraph は PC に未導入。入れる前に安全確認（package-security-scan）を行い、許可を得る

## 10.5 試作で分かって変えた点（2026-11-14 追記。上の記述と食い違う場合はこちらが優先）
- **時定数を一つに絞れない記録への対応（6.2〜6.4 への追加）**：単調に揺れ続けるだけの記録では、
  「出力 1% あたりの変化の速さ（K÷T）」と「むだ時間」は求まるが、時定数は一つに絞れない。
  当てはまりが最良から 2 ポイント以内の候補の時定数が 3 倍を超えて散らばるとき「絞れない」と判定する。
  このときも数値の提案は出し、ゲインは変化の速さとむだ時間から計算し、
  積分時間は「推定した T と 2×(τc+L) の大きいほう（上限 4×(τc+L)）」にする（安全側）。
  画面の時定数の欄は「一つに絞れません」と表示する
- **むだ時間の候補**：短いところは記録の間隔ごとに細かく探す（粗いと時定数が約 2 倍ずれた）
- **揺れの判定（6.7）**：「温度の揺れ」は、測定値が設定値の上と下に、合わせて 4 回以上振れること（山と谷が合わせて 4 つ以上＝2 往復）。
  設定値変更のあとの揺れの周期は、1 つ目と 2 つ目の山の間隔（1 つ目の 1 割に満たない山は数えない）
- **ノイズの扱い（6.7。2026-11-15 追記）**：行き過ぎ量は、測定値の細かいばらつき（ノイズ）の 6 倍以下なら 0 とみなす。
  「落ち着いた」とみなす幅は、「変化幅の ±5%」と「ノイズの 6 倍」の大きいほうにする。
  ノイズがごく小さい記録では、「ノイズの 6 倍」の代わりに「入力レンジの 0.1%」を下限として使う
  （設定値の変更が小さい記録で、ノイズだけで「行き過ぎが大きめ」と出るのを防ぐため）
- **推定できない場合の追加（6.3。2026-11-15 追記）**：時定数が探した範囲の下限（記録の間隔の 2 倍）に張り付いたときも、
  数値の提案を出さず、「反応が記録の間隔に比べて速すぎて、遅れを推定できません」と示す
- **プロファイルの保存と読み込み（5 章。2026-11-15 追記）**：別の名前が同じファイル名になる場合は、上書きせずに断る。
  読み込むときに値を検査し、外れているファイル（刻みが 0、知らない単位など）は一覧に出さない
- **微分動作によるばたつきの見積もり（6.4）**：ゲイン × 微分時間 ×（となり合う記録のばらつき ÷ 記録の間隔）で見積もる
- **Python 3.14 を使う。pytest-qt は使わない**（テスト用の部品は pytest だけ）
- **入力値の記憶**：窓を閉じるときに P・I・D・入力レンジ・調整の好み・プロファイル名を覚える
